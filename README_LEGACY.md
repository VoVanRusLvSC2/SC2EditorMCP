# SC2EditorMCP documentation

SC2EditorMCP is a Model Context Protocol server for generating and editing
StarCraft II maps and mods. It covers mission, melee ladder and arcade generation,
terrain, water, objects, game Data, GUI triggers, Galaxy scripts, cutscenes, UI
and localization. The browser workbench is optional.
